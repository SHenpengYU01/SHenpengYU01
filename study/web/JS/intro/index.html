    JavaScript 基础语法

    JavaScript 是一门运行在浏览器（以及 Node.js 等宿主环境）里的解释型语言。console、document 这些 API 由宿主环境提供，并非语言本身。

    主要参考：MDN Web Docs

    变量声明

    var / let / const 三种方式。let、const 是 ES6 引入的块级声明，优先用 const，需要重新赋值时用 let，避免用 var。

    关键字 作用域 可重新赋值 变量提升 重复声明
    var 函数作用域 ✅ 提升并初始化为 undefined 允许
    let 块作用域 ✅ 提升但有暂时性死区（TDZ） 报错
    const 块作用域 ❌ 同上 报错

    暂时性死区（TDZ）

    let/const 也会提升，但在声明之前访问会直接抛 ReferenceError，而不是返回 undefined： 

    console.log(a); // undefined（var 提升）
var a = 1;
console.log(b); // ReferenceError（TDZ）
let b = 2;

    数据类型

    7 种原始类型 + 1 种引用类型：

    • 原始类型：string、number、boolean、null、undefined、bigint、symbol
    • 引用类型：object（数组、函数、日期等都是对象）

    undefined 表示「变量已声明但未赋值」，null 表示「刻意的空值」。两者 == 相等、=== 不相等。

    typeof null 的坑

    typeof null === "object" 是历史遗留 bug。判断 null 直接用 === null。

    相等判断与类型转换

    • === / !==：严格比较，不转换类型，日常优先使用。
    • == / !=：会做隐式类型转换，容易反直觉，尽量避免。
    1 == "1";            // true（转换后比较）
1 === "1";           // false
null == undefined;   // true
null === undefined;  // false

    Truthy / Falsy：条件判断里，以下 6 个是 Falsy（false），其余都是 Truthy：

    false、0、""（空字符串）、null、undefined、NaN

    运算符

    • 算术：+ - * / % **（** 为幂运算）
    • 比较：> < >= <= == === != !==
    • 逻辑：&& || !
    • 空值合并 ??：左侧为 null/undefined 时取右侧
    • 可选链 ?.：属性为 null/undefined 时短路返回 undefined，而不是报错
    • 三元：cond ? a : b

    + 的隐式转换

    + 遇到字符串会拼接而非相加，而 -、*、/ 会尝试转成数字： 

    1 + "2" === "12";   // 字符串拼接！
1 - "2" === -1;     // 隐式转数字

    控制流

    • if / else if / else
    • switch（匹配用严格等于 ===）
    • for、while、do...while
    • for...of：遍历可迭代对象的值（数组、字符串、Map、Set）
    • for...in：遍历对象的可枚举键（含原型链，慎用）
    • break / continue
    for (const n of [1, 2, 3]) { /* 拿到的是值 */ }
for (const k in { a: 1 }) { /* 拿到的是键 "a" */ }

    数字

    number 是双精度浮点数（IEEE 754），同时表示整数与小数；超范围整数用 bigint。

    Number.isInteger(1);   // true
Number.isNaN(NaN);     // true（比全局 isNaN 严格，不做类型转换）
Math.floor(3.7);       // 3
Math.round(3.4);       // 3
Math.random();         // [0, 1) 随机数

    浮点精度

    二进制无法精确表示某些小数，比较时不要直接用 ===： 

    0.1 + 0.2 === 0.3;   // false（实际是 0.30000000000000004）
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON; // true，正确做法
    NaN 不等于任何值（包括自身），用 Number.isNaN 判断。

    字符串

    创建与特性

    let a = '单引号';
let b = "双引号";
let c = `模板字符串`;   // ES6，支持换行与 ${} 插值

    字符串是不可变的：任何操作都返回新字符串，不修改原值。

    常用方法

    查找与判断

    • indexOf(str) / lastIndexOf(str)：找不到返回 -1
    • includes(str)：返回布尔值
    • startsWith(str) / endsWith(str)
    • charAt(i)：取第 i 个字符（也能用 str[i]）

    截取与分割

    • slice(start, end)：支持负数（从末尾算）
    • substring(start, end)：负数按 0 处理
    • split(sep)：按分隔符分割成数组

    替换与大小写

    • replace(re)：只替换第一个，用正则 /g 标志替换全部
    • replaceAll()：全部替换（ES2021）
    • toUpperCase() / toLowerCase()

    其他

    • trim() / trimStart() / trimEnd()：去空白
    • repeat(n)：重复
    • padStart(len, str) / padEnd(len, str)：补全
    • concat()：拼接（更常用 + 或模板字符串）

    模板字符串

    const name = "Alice";
console.log(`Hello, ${name}!`);   // 插值

    标签模板（tagged template）用一个函数处理模板字符串，是 styled-components 等库的实现基础。

    字符串与类型的互转

    String(123);        // "123"
(123).toString();   // "123"
parseInt("123px");  // 123（尽量解析，遇到非数字停止）
parseFloat("3.14"); // 3.14
Number("42");       // 42（严格，无法解析返回 NaN）

    Unicode 与遍历

    字符串可用 for...of 按码点遍历，正确处理 emoji 等多字节字符： 

    [..."Hello"];          // ["H", "e", "l", "l", "o"]
Array.from("👋").length; // 1（按码点）
"👋".length;            // 2（按 UTF-16 码元，坑！）
