    SkillRL: Evolving Agents via Recursive Skill-Augmented Reinforcement Learning

    论文信息：Peng Xia et al., arXiv:2602.08234v1 (2026.02)。 论文原文 提出 SkillRL——一个把 agent 轨迹蒸馏为层级技能库，并让技能库与策略在 强化学习中递归共演化的框架。

    1. 摘要 (Abstract)

    • 核心问题：LLM agent 虽然在复杂任务上表现强，但通常是“单次执行、彼此隔离”， 不能有效从过去经验中学习。
    • 现有不足：memory-based 方法多直接存 raw trajectories，冗长、噪声大、 冗余高，难以抽取高层、可复用的行为模式。
    • 提出方案 (SkillRL)：
    • 用 experience-based distillation 把成功/失败轨迹转成紧凑技能；
    • 构建 hierarchical SkillBank，区分通用技能与任务特定技能；
    • 在 RL 训练中引入 recursive evolution，让技能库与策略共同演化。
    • 效果：在 ALFWorld、WebShop 和 7 个 search-augmented QA 任务上达到 SOTA， 相比强基线提升超过 15.3%，同时降低 token footprint。

    2. 引言 (Introduction)

    • 背景：LLM agent 已可在 web navigation、deep research 等任务中工作， 但每次任务执行基本是 episodic 的，不能把过往成功/失败有效迁移到新任务。
    • 记忆方法的问题：直接存原始轨迹虽然直观，但轨迹往往又长又乱， 包含大量探索、回退和噪声，模型难以抓住真正有用的决策规律。
    • 作者的关键洞见：高效的经验迁移不应停留在“记住经历”， 而应做成 抽象 (abstraction)。人不会记住每个动作，而会内化成技能。
    • SkillRL 的定位：连接“原始经验”和“策略提升”， 不只是存 memory，也不只是 RL 调 policy，而是把经验蒸馏成技能， 再让技能与策略在训练中递归共演化。

    3. 相关工作 (Related Work)

    • LLM Agents：ReAct、Reflexion、AutoGen、CAMEL 等提升了 agent 交互能力， 但多数仍把每次任务当作孤立事件。
    • Memory Mechanisms：RAG、raw trajectory memory、procedural memory、 self-evolving memory 等都试图让 agent 记住经验，但常受噪声、冗余和检索质量所限。
    • Skill + RL / Continual Learning：SkillRL 把 agentic skills 放到 continual learning 和 reinforcement learning 视角下，不只是“存知识”，而是让 skill library 成为 与 policy 一起优化的动态对象。

    4. 方法论 (Methodology) —— 核心章节

    4.1 预备知识 (Preliminaries)

    • 论文考虑一个交互环境 \(\mathcal{E}\)，agent 在每一步观察状态、执行动作、 得到 reward，形成完整 trajectory： [ \tau=(o_0,a_0,r_0,\ldots,o_T,a_T,r_T) ]
    • LLM agent 的策略写作： [ \pi_\theta(a_t\mid o_{\le t}, d, c) ] 其中 \(d\) 是任务描述，\(c\) 是额外上下文（如 skills、demonstrations）。
    • 目标是在上下文长度受限下，最大化期望回报。
    • RL 优化器采用 GRPO，即基于组内相对奖励做 PPO-style 更新； SkillRL 不是发明新 RL 算法，而是在 GRPO 上叠加 skill augmentation。

    4.2 总体框架 (Overview)

    SkillRL 由三部分组成：

    1. Experience-based Skill Distillation：把原始轨迹蒸馏成技能。
    2. Hierarchical Skill Library (SkillBank)：把技能组织成两层库。
    3. Recursive Skill Evolution：在 RL 中根据失败动态更新技能库。

    4.3 经验蒸馏 (Experience-based Skill Distillation)

    • 先用 base model 在环境中 rollout，收集多样化轨迹。
    • 与只保留成功样本的方法不同，SkillRL 同时保留：
    • 成功轨迹 \(\mathcal{T}^{+}\)
    • 失败轨迹 \(\mathcal{T}^{-}\)
    • 原因：失败轨迹能暴露 failure mode 和边界条件， 这些信息仅从成功样本里很难推断出来。

    对两类轨迹采用不同处理：

    • 成功轨迹：提炼出导致任务完成的关键策略、关键决策点与可迁移模式： [ s{+}=\mathcal{M}_T(\tau, d) ]
    • 失败轨迹：不直接放进上下文，而是压缩成 failure lessons： [ s{-}=\mathcal{M}_T(\tau, d) ] 重点提炼：
    • 失败发生在哪；
    • 错误 reasoning / action 是什么；
    • 正确做法应该是什么；

    • 如何概括成防止同类失败的一般原则。

    • 核心作用：把 verbose failed episodes 变成紧凑反事实经验， 让失败也成为高价值训练信号，而不是上下文噪声。

    4.4 层级技能库 SkillBank (Hierarchical Skill Library)

    作者参考 Agent Skills 的设计，把蒸馏结果组织为两层：

    1. General Skills \(\mathcal{S}_g\)：跨任务通用的战略性原则。
    2. 如探索顺序、前置条件检查、进度跟踪、终止条件验证。
    3. Task-Specific Skills \(\mathcal{S}_k\)：某类任务专属启发。
    4. 如特定动作顺序、任务特定失败模式、某环境下的高效策略。

    完整技能库： [ \mathrm{SkillBank}=\mathcal{S}g\cup\bigcup_k ]}^{K}\mathcal{S

    每个 skill 都结构化为：

    • concise name
    • principle
    • when_to_apply

    Skill Retrieval

    • 推理时，general skills 总是加载。
    • task-specific skills 则基于任务描述与 skill embedding 的语义相似度检索： [ \mathcal{S}_{\text{ret}}=\text{TopK}( {s\in\mathcal{S}_k:\text{sim}(e_d,e_s)>\delta}, K) ]

    • 最终策略条件化在： [ a_t\sim\pi_\theta(a_t\mid o_{\le t}, d, \mathcal{S}g, \mathcal{S}) ]}

    • 关键收益：skill distillation 相比 raw trajectories 可实现约 10–20× 的 token 压缩，同时不是丢信息，而是提升 reasoning utility。

    4.5 递归技能演化 (Recursive Skill Evolution)

    Cold-start Initialization

    • 作者指出：即使给模型 skills，base model 也未必会“用 skill”。
    • 因此先做一轮 cold-start SFT：
    • 由 teacher model 生成带 skill 的 reasoning traces；
    • 演示如何检索、理解和应用 skills；
    • 用这些 demonstrations 对 base model 做监督微调。
    • 得到的 \(\pi_{\theta_{\text{sft}}}\) 同时作为：
    • RL 训练起点；
    • KL regularization 的 reference policy。

    Dynamic Evolution

    • 静态 skill library 无法覆盖 agent 训练中遇到的所有新情形。
    • 因此 SkillRL 在每个 validation epoch 后检查各任务类别表现：
    • 若某类任务准确率 \(Acc(C)<\delta\)，触发该类技能演化。
    • 然后：
    • 收集失败验证轨迹 \(\mathcal{T}_{\text{val}}^{-}\)；
    • 用 teacher 分析这些 failure，找出当前技能未覆盖的 gap；
    • 生成新技能或改写旧技能： [ \mathcal{S}{\text{new}}=\mathcal{M}_T(\mathcal{T}) ]}}^{-},\mathrm{SkillBank

    • 更新技能库： [ \mathrm{SkillBank}\leftarrow \mathrm{SkillBank}\cup \mathcal{S}_{\text{new}} ]

    • 直观理解：policy 变强 → 遇到更难情形 → 暴露新失败模式 → skill library 扩充 → 进一步帮助 policy 进步，形成正反馈循环。

    4.6 基于技能增强的 RL 优化

    • 每个任务先检索相关 skills，再采样一组 trajectories，得到二值奖励。
    • 归一化 advantage 后，用 GRPO 更新策略。
    • 技能增强体现在：policy ratio 与 KL regularization 都是在 skill-augmented context 条件下定义的。
    • 因而 SkillRL 的提升来自“技能增强 + 递归演化”，不是换了 RL objective。

    5. 实验 (Experiments)

    5.1 实验设置 (Experimental Setup)

    • 环境 / 任务：
    • ALFWorld：文本家庭操作环境。
    • WebShop：模拟在线购物环境。
    • 7 个 search-augmented QA 任务：
      • 单跳：NQ、TriviaQA、PopQA
      • 多跳：HotpotQA、2Wiki、MuSiQue、Bamboogle
    • 基础模型：Qwen2.5-7B-Instruct。
    • Teacher 模型：OpenAI o3，用于 skill distillation 和 SFT 数据生成。
    • RL 设置：GRPO，learning rate 1e-6，batch size 16，group size 8。
    • 检索设置：task-specific skills Top-K=6；失败轨迹收集阈值 \(\delta=0.4\)。

    5.2 主要结果 (Main Results)

    ALFWorld / WebShop

    • SkillRL 在 ALFWorld 上达到 89.9%，在 WebShop 上达到 72.7%。
    • 超过 prompt-based baselines、vanilla RL baselines 和 memory-augmented RL。
    • 相比作为底座优化器的 GRPO，SkillRL 在 ALFWorld 上 从 77.6% → 89.9%，说明增益来自 skill augmentation 机制。
    • 在复杂子任务如 Cool、Pick2 上提升尤其大，说明 task-specific skills 对多步规划和状态跟踪帮助显著。

    Search-Augmented QA

    • SkillRL 平均分达到 47.1%，优于 Search-R1（38.5%）与 EvolveR（43.1%）。
    • 在多跳任务上尤其强，如 Bamboogle 明显超过 EvolveR，说明层级技能能有效支持 多步信息整合。
    • 尽管只在 NQ 和 HotpotQA 上训练，仍能迁移到 TriviaQA、2Wiki 等 OOD 任务， 说明搜索策略技能具有任务无关性。

    与闭源模型比较

    • SkillRL + Qwen2.5-7B-Instruct 在 ALFWorld 上显著超过 GPT-4o 和 Gemini-2.5-Pro。
    • 这表明：结构化经验技能 可以部分弥补模型尺度差距。

    5.3 分析 (Analysis)

    消融实验

    • 去掉层级结构：ALFWorld 降 13.1%，WebShop 降 11.3%。
    • 说明 general skills 提供的是不可替代的底层战略支撑。
    • 用 raw trajectories 替代 skill library：降幅最大，可达 25%。
    • 直接证明：抽象优于记忆，原始轨迹的噪声和冗余会伤害迁移。
    • 去掉 cold-start SFT：约 20% 的明显下降。
    • 说明模型必须先学会“怎么用 skill”，再谈 skill 增强 RL。
    • 去掉 dynamic evolution：约 5.5% 的下降。
    • 说明 skill library 必须是动态组件，而非一次性静态数据库。

    Skill Library Growth

    • 初始 skill library 共 55 个 skills：
    • 12 个 general
    • 43 个 task-specific
    • 到训练结束增长到 100 个 skills：
    • general 从 12 → 20
    • task-specific 从 43 → 80
    • 说明随着训练深入，增长主要来自任务专属技能补全。

    Context Efficiency

    • raw memory baseline 平均 prompt 长度约 1450 tokens， SkillRL 平均明显更低（约减少 10.3%）。
    • 说明它不是靠塞更多上下文取胜，而是靠更高密度的 skill abstraction。

    Evolution Dynamics

    • 有 recursive skill evolution 时，训练收敛更快、上限更高。
    • SkillRL 在约 60 个训练 step 就能超过 80% success rate； 无演化版本需要更多步且峰值更低。
    • 这说明动态技能注入为策略持续提供“及时的高层指导”。

    定性分析

    • 在 WebShop 中，agent 会同时调用通用搜索原则和商品筛选启发。
    • 在 ALFWorld 中，agent 能把高层规划 skill 与具体动作约束 skill 协同使用。
    • 说明它不是单纯记住轨迹，而是形成了结构化任务理解。

    6. 结论 (Conclusion)

    • SkillRL 提出了一条“轨迹 → 技能 → 策略提升”的新路径： 把原始经验蒸馏成紧凑、可复用的 skills，并在 RL 中递归演化。
    • 它的核心不在于记住更多经历，而在于把经验抽象成更高密度、更可迁移的行动原则。
    • 实验表明，层级 SkillBank、cold-start SFT 和 recursive evolution 共同构成 了该方法成功的关键。
    • 这说明：对 agent 而言，从经验到技能的抽象 是比简单 memory 存储更有效的 长期学习范式。
